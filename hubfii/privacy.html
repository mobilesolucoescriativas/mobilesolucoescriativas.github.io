1. Informações gerais

Esta Política de Privacidade descreve como o aplicativo HubFII, desenvolvido por Mobile Soluções Criativas, trata informações dos usuários.

2. Dados coletados

O aplicativo pode armazenar localmente informações inseridas pelo usuário para funcionamento das funcionalidades principais. Essas informações permanecem no dispositivo, salvo quando alguma funcionalidade externa for expressamente utilizada.

3. Anúncios

O aplicativo pode utilizar o Google AdMob para exibição de anúncios. O Google pode coletar identificadores e dados técnicos conforme suas próprias políticas para veiculação, medição e segurança dos anúncios.

4. Compras e assinaturas

Quando houver compras ou assinaturas, o processamento é realizado pela Google Play. A Mobile Soluções Criativas não recebe dados completos de pagamento do usuário.

5. Segurança

Adotamos boas práticas para proteger as informações tratadas pelo aplicativo, respeitando os limites técnicos das plataformas utilizadas.

6. Contato

Em caso de dúvidas, entre em contato pelo e-mail mobile.solucoescriativas@gmail.com.
